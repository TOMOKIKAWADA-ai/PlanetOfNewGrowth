# Search Survive Three

Three.js / Vite 製の見下ろし型 3D サバイバルゲームです。Godot はランタイムから外し、Web ブラウザだけで起動します。

## 起動方法

```powershell
npm install
npm run dev
```

表示された URL、通常は `http://127.0.0.1:5173/` をブラウザで開きます。

本番ビルド確認:

```powershell
npm run build
```

## 操作

GAME START → 世界観のプロローグ → キャラクター選択 → 第1～5章の出撃前会話・戦闘・戦闘後会話 → エンディング。勝利後の結果画面から次章へ進めます。敗北時は同じ章をやり直せます。
戦闘は4分制です。開始3分で母卵が現れ、残り1分で倒せなければ時間切れになります。人間形態の射撃は自動で、通常の近接攻撃はありません。
ストーリーはクリック・Enter・Space・コントローラーの×で進みます。文字送り中は全文表示、全文表示後は次のページへ進みます。
BACKで前のページ、LOGで既読の文章を確認、AUTOで自動送り、SKIPで現在のシーンを省略できます。会話ログはEsc／○でも閉じられます。
戦闘後会話は各章の勝利時に再生し、戦闘とタイマーは停止します。結果画面から読み返せます。敗北・時間切れでは再生しません。
台本は `src/story-data.js` と `src/story-continuation.js`、章ごとの戦闘設定は `src/campaign.js`、演出と操作は `src/story.js`、画面デザインは `src/story.css` で編集できます。
現在の台本を読み物として確認する場合は `docs/implemented-story-script.txt` を参照してください。`node scripts/export-story-text.mjs` で実装データから再生成できます。
一般市民は根を張った植物・機械の姿で、旧人類の体を模した三人を恐れる者もいます。市民は揮発性物質でしか会話できず、その発話は端末が言葉に変えて全角の（ ）で表示します。`assets/story` の市民画を物語画面へ表示し、救助は土ごとの移動槽と避難所での給水として描いています。市民の立ち絵は `src/story-data.js` の `CIVILIAN_ART` から割り当てています。
各章の出撃前・戦闘後会話には、選択キャラクターによる台詞の変化があります。第2章では行方不明の兵士サヨとユラを探し、深淵の花々と互いに望んで暮らす二人に出会います。中央は二人を追討し、主人公三人を中央から遠ざけます。その間に司令官エンジュがクーデターを起こし、植物人類を滅ぼして旧人類型の者だけの世界を作ると宣言します。第3章では深淵の花々が旧人類の遺伝子を移植された植物だったと判明し、第4章で焼却を止め、改造された巨大母卵との最終戦へ進みます。
主人公三人は植物人類を市民として守り、人と和解した深淵の花々も守ると決めます。中央の追討隊、暴走卵、市民を襲う未和解の花々のいずれとも戦い、出自だけで敵味方を決めません。
第2～5章の戦闘は仮実装として既存の草原・水没マップを再利用し、章ごとに色、出現数、母卵の耐久を変えています。第2章で攻撃するのは暴走した卵と母卵で、意思を持つ花々は救助対象と共に守る設定です。追討、クーデター、証拠回収、四地区の判断と焼却停止は会話と結果で進行し、専用の追討隊AIや操作可能な目標物はまだありません。
中央の追討隊と未和解の花々は台本上の敵であり、現時点の3D戦闘では既存の敵モデルと母卵戦を使う仮表現です。
F3のデバッグメニューはキャラクター選択中と戦闘中・結果画面で開けます。章を直接選ぶか、「この戦闘をスキップ」で戦闘後の会話へ進めば、最後まで短時間で確認できます。
台本データの検証は `npm test`。演出仕様とブラウザ検証方法は `docs/story-direction.md` を参照してください。

- WASD / 矢印キー: 移動
- Q: 人間形態と鳥形態を切り替え
- E: 人間形態でバースト技
- 鳥形態: 卵や母卵へ近づくと自動で急降下
- Esc: 一時停止
- R: 再開始
- F3: 章移動・戦闘スキップのデバッグメニュー
- F4: 開発情報表示

### PS5コントローラー（DualSense）

- 左スティック / 方向キー: 移動、メニュー選択
- ×: メニュー決定。キャラクター画面では候補を選び、続けて「出撃」を押す
- レベルアップ画面: 方向キー / 左スティックで強化を選び、×で決定。選択中の候補は黄色い枠で表示
- □ / R1: バースト技
- △: 人間形態と鳥形態を切り替え
- OPTIONS: 一時停止 / 再開
- ○: メニューを戻る、ポーズ解除
- CREATE: ポーズ中に再開始

USBまたはBluetoothで接続し、ブラウザ上でいずれかのボタンを押すと認識されます。
コントローラーが接続されている間は、誤操作を避けるためゲーム内のキーボード操作を無効にします。取り外すとキーボード操作に戻ります。メニューでは白い枠がコントローラーのカーソル、キャラクターの金色の「選択中」が出撃対象です。

### スマートフォン

スマートフォンのブラウザでは、画面左下のスティックをドラッグして移動します。右下の「変身」と「バースト」をタップし、右上の「一時停止」で操作ガイドと再開ボタンを開けます。攻撃は自動です。タイトル、会話、キャラクター選択、強化選択は画面をタップして進めます。縦向き・横向きの両方に対応しています。

同じWi-Fi上のスマートフォンで開く場合は、開発サーバーを `npm run dev -- --host 0.0.0.0` で起動し、PCのローカルIPアドレスと表示されたポートを指定します。スマートフォンから `localhost` を指定してもPCのサーバーには接続できません。

## 実装内容

- Three.js の単一 Web アプリとして実装
- 現在の見た目はプレーンな低ポリゴン Primitive 基準
- `assets/player/tsukimi_base.glb` を自キャラ表示として有効化しています
- 背景装飾は `assets/background` のGLBのみを使用し、Primitiveの草・石・木は無効化しています
- `src/config.js` の `visuals.useAssetModels` を `true` に戻すと、GLB アセット読み込みを再有効化できます
- 卵の成熟、孵化、増殖、卵ゼロ時の即時復帰スポーン
- 産卵獣、追跡敵、射撃敵、守護敵
- 鳥形態の上空移動、自動捕食、母卵への自動急降下
- 人間形態の自動射撃、特殊弾、バースト技、範囲パルス強化
- 経験値、レベルアップ、ランダム 3 択強化
- 母卵 HP バーと画面外アラート
- 敵検索用の空間グリッド
- 弾と経験値オーブのオブジェクトプール
- 草、岩、木の `InstancedMesh` 配置
- 水没ステージの水面シェーダー（波の法線、浅瀬の透け、コースティクス、岸と水没建物まわりの白波）と、島・岸・水底をブレンドする地面シェーダー（`src/water-stage.js`）

## 主な設定場所

- `src/config.js`: ゲーム数値、カメラ、スポーン、敵、強化候補、アセットパス
- `src/config.js` の `performance`: 高DPI描画、アンチエイリアス、シャドウ、装飾数、粒子数、卵ライトの軽量化設定
- `src/entities.js`: プレイヤー、卵、敵、弾、経験値
- `src/main.js`: ゲームループ、スポーン、勝敗、演出、環境生成
- `src/styles.css`: HUD とレスポンシブ UI
