# ストーリー演出

参考：ユーザー提供「レコーディング 2026-09-22 222126.mp4」（約102秒）。
動画の画面構成を参考にし、文章とキャラクターは『芽吹きの惑星』の既存設定に合わせて新規作成。

## 動画から確認した要素

- 0〜20秒付近：同じ背景上に複数の立ち絵。下部の暗いグラデーションに話者名と短い台詞。
- 27〜61秒付近：話者の切り替えに合わせた寄りと構図の変化。表情で反応を補う。
- 68秒付近：黒い画面に地の文を置き、場面の間を作る。
- 75〜88秒付近：背景主体の状況説明から人物の会話へ戻る。
- 上部にログ／自動送り等の小さな操作UI。途中に選択肢も見られる。

※確認は映像フレームの観察に基づく。音声の文字起こし・音響分析は実施していない。

## ゲームへの反映

GAME START → プロローグ → キャラクター選択 → 第1～5章の出撃前会話・戦闘・戦闘後会話 → エンディング。各章の勝利結果から次章へ進む。
原作動画の台詞・キャラクター・画像は利用していない。
新しい分岐システムは追加せず、既存のキャラクター選択を水源担当の出撃・帰還台詞へ反映。

背景は既存の `assets/promo`、人物は既存の5種の表情差分を利用。
話者以外を暗くし、話者は少し拡大。要所でさらに寄り、地の文では立ち絵を退場させる。
会話中は話者と直前の相手を最大二人だけ表示し、左右の立ち絵を鏡像にして内側へ向ける。スマホ幅では話者一人だけを大きく表示する。文字は背景から独立した濃いパネルに置き、44px以上の操作ボタンと画面の安全領域を確保する。
短い文字送り、句読点の間、暗転、前ページ、既読ログ、自動送り、シーン単位のスキップを実装。
NPCは名前と役割を表示し、市民には `assets/story` の根を張った植物・機械の絵を使う。旧人類型の兵士立ち絵を代用しない。市民の原画は淡い背景ごと資料肖像のようにフレームへ収め、暗いゲーム画面に合う彩度と陰影へ調整する。一般市民は揮発性物質でしか会話できず、端末が信号を言葉に変える。市民の発話は全角の（ ）で囲み、兵士やエンジュの音声通信と区別する。会話中は背後のUIをinertにし、入力フォーカスを会話画面内に保持する。
新規の会話音声、口パク、Live2Dは含まない。
行方不明の兵士サヨとユラには、既存の一般兵の表情画像を使用する。深淵の花々も揮発性物質で会話し、台詞を全角の（ ）で囲む。

## 台本上の話し方

- ツキミ：人と状況を見て役割を整理する。軽口は短く、相手の話が終わるまで待つ。
- アカメ：まず自分が引き受けようとする。口より、荷車や種箱に手を貸す行動で気遣う。
- キイチゴ：肩当て、食事、記録など目の前の物から軽口を返す。愚痴を言いながら仕事はする。
- エンジュ：三人を育てた防除隊司令。旧人類型の肉体を復活させるためクーデターを起こし、植物人類の全地区焼却と花々の組織利用を命じる。
- ミナリ：ハス型の住民代表。旧人類型の兵士の姿に怯えながら、土地勘と移動槽を提供する。救助への感謝と恐怖を別々に語る。
- リンドウ：殻のある観測員。種箱を運搬器に残したまま、アカメが近づきすぎない距離を保つ。
- ケシ：避難した六人の一人。外見への嫌悪を伝え、助けられてもすぐには安心できない。
- クヌギ：避難した六人の一人。誰が運んだのか確かめ、先入観と救助の事実を結び直し始める。
- サヨ、ユラ：半年間行方不明だった防除兵。深淵の花々と互いの意思で伴侶として暮らすため追討され、三人に逃げ道を託す。
- ヨル、ネム：深淵の花々。黒い卵由来の植物に旧人類の遺伝子を移植された存在。揮発性物質で話し、愛する兵士の意思を尊重する。
- フキ：医療区で避難に必要な薬と水を運ぶ市民。
- イバラ：ガイア監査機構の技師。監視を止めずに判断権を住民へ移す手順を探す。
- キヌ：クーデターで排除名簿に載せられる市民。最後に防除線の門を通ることで、制度の変更を示す。
- ガイア：防除監査AI。エンジュの権限による命令と危険の観測を区別して記録し、最後は四地区の判断に従う。

## 第1章からエンディングまでの実装範囲

ユーザーと検討した『芽吹きの惑星――防除線のこちら側』を採用。前日のシラユリ観測所救助をプロローグで要約し、一斉孵化まで六日の朝から第1章へ入る。
既存の草原戦闘をハスノ区の水源外縁に見立てる。選択キャラクターが増殖を抑え、母卵を破壊する。非選択の二人とミナリが救助側を担当する。
六人救出・育苗床の喪失は固定の物語であり、護送AI、救助用オブジェクト、ポンプ耐久値、新しい勝敗条件は追加していない。市民の姿は既存の `assets/story` の画像を物語画面に表示する。戦闘中のNPCモデルや新しい地域背景は追加していない。
死亡・時間切れは敗北画面になり、同じ章をやり直せる。第1章の勝利後は第2章へ進み、行方不明の兵士サヨとユラを捜索する。二人は深淵の花々と信頼・愛情・性愛を持って暮らしている。中央は二人を追討し、主人公三人を外縁監査所へ遠ざける。その不在中にエンジュが評議会を拘束してクーデターを宣言し、植物人類の全地区焼却と旧人類型の者だけによる世界を呼びかける。第3章で花々への旧人類遺伝子移植と再生計画が明らかになり、第4章で四地区の拒否を届け、第5章で改造された巨大母卵を止める。エンジュは発令権を失い拘束される。花々との類似は三人の動機になるが、血や姿で守る相手を選ばないという決断で結末に至る。
三人は植物人類を市民として守り、人と和解した花々を仲間として守ると宣言する。中央の追討隊、暴走卵、市民を襲う未和解の花々という三方の脅威にも立ち向かう。花々を一括して敵とせず、和解した者の意思と攻撃する者の行動を分けて判断する。
第2～5章の戦闘は既存の草原・水没環境を仮に再利用する。章ごとに背景色・地面色・初期敵数・母卵の耐久を変える。第2章で倒すのは花々と二人を襲う暴走卵・母卵であり、花々を敵として攻撃する演出ではない。追討隊、クーデターの制圧、市民の判断、巨大母卵と司令官の接続は台本上の出来事で、専用の3Dステージや操作可能な目標物はまだ作っていない。F3で章移動と現在の戦闘のスキップができる。
中央の追討隊と未和解の花々の攻撃は会話で表現し、専用の敵AI・モデルはまだ設けていない。ゲームプレイで倒す対象は既存の敵と母卵で、和解した花々や市民が標的になることはない。

`fiction-scene-voice`に沿って、セリフを短く分割し、肩当て・移動槽・給水管・種の箱・音声記録を地の文で受け渡す。損失を語る部分は軽口を止める。市民の嫌悪を救助で即座に解決させず、距離を求める意思を三人が尊重する。
前日の出来事を知らないと分からない「壁」の掛け合いは外し、「母卵」「防除線」は初出で説明する。根を張った市民の移動は土ごとの移動槽と荷車、避難後は根鉢への給水として具体的に書く。

## 検証

- `npm test`：全キャラクターの台本、話者、表情、ページ長、ステージ分岐。
- `npm run build`：本番ビルド。
- `npm run dev -- --port 5183` の起動後、Playwrightが利用できる環境で `node scripts/check-story.mjs`：実ブラウザで会話操作、レスポンシブ表示、勝敗分岐、会話中の戦闘停止、再読を確認する。
- `node scripts/check-campaign.mjs`：F3で各章の戦闘を飛ばし、第1章からエンディングまでの遷移を確認する。
- Playwrightが別の場所にある場合は `PLAYWRIGHT_MODULE` にそのモジュールのパスを指定。`STORY_TEST_URL`でテスト先URL、`STORY_TEST_BROWSER`でブラウザチャネルを指定可能（既定はmsedge）。
- ブラウザ検証では、テスト時のHTTP応答だけに状態参照を追加する。製品のF3メニューには、章移動と戦闘スキップを意図的に残す。
