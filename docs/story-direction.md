# ストーリー演出

参考：ユーザー提供「レコーディング 2026-09-22 222126.mp4」（約102秒）。
動画の画面構成を参考にし、文章とキャラクターは『芽吹きの惑星』の既存設定に合わせて新規作成。

## 動画から確認した要素

- 0〜20秒付近：同じ背景上に複数の立ち絵。下部の暗いグラデーションに話者名と短い台詞。
- 27〜61秒付近：話者の切り替えに合わせた寄りと構図の変化。表情で反応を補う。
- 68秒付近：黒い画面に地の文を置き、場面の間を作る。
- 75〜88秒付近：背景主体の状況説明から人物の会話へ戻る。
- 上部にログ／自動送り等の小さな操作UI。途中に選択肢も見られる。

※確認は映像フレームの観察に基づく。音声の文字起こし・音響分析は実施していない。

## ゲームへの反映

GAME START → プロローグ → キャラクター選択 → 出撃前会話 → 戦闘 → 第1章の母卵撃破時のみ帰還会話 → 結果。
原作動画の台詞・キャラクター・画像は利用していない。
新しい分岐システムは追加せず、既存のキャラクター選択を水源担当の出撃・帰還台詞へ反映。

背景は既存の `assets/promo`、人物は既存の5種の表情差分を利用。
話者以外を暗くし、話者は少し拡大。要所でさらに寄り、地の文では立ち絵を退場させる。
会話中は話者と直前の相手を最大二人だけ表示し、左右の立ち絵を鏡像にして内側へ向ける。スマホ幅では話者一人だけを大きく表示する。文字は背景から独立した濃いパネルに置き、44px以上の操作ボタンと画面の安全領域を確保する。
短い文字送り、句読点の間、暗転、前ページ、既読ログ、自動送り、シーン単位のスキップを実装。
NPCは名前と役割を表示し、市民には `assets/story` の根を張った植物・機械の絵を使う。旧人類型の兵士立ち絵を代用しない。市民の原画は淡い背景ごと資料肖像のようにフレームへ収め、暗いゲーム画面に合う彩度と陰影へ調整する。会話中は背後のUIをinertにし、入力フォーカスを会話画面内に保持する。
新規の会話音声、口パク、Live2Dは含まない。

## 物語エンジン（2026-10 改稿）

旧台本は全員が礼儀正しく、謎がなく、ジレンマが裏道の発見で即座に消えていた。`story-plot-engineer` の診断表に沿って、次の軸で組み直した。中盤の章は、毎回「新しい事実」か「代償のある選択」を一つ持ち込み、同じ戦いの繰り返しにしない。

- **謎（引き）**：卵はどこから来るのか。プロローグで「一年前の冬、黒い卵が降ってきた」「同じ冬、白蓮保管庫で三人が目を覚ました」を並べて置く。白蓮保管庫は人類が手放した肉体を眠らせた塔（`world-awakening.png` の、蓮の中で眠る人体）。第1章で母卵の内殻に名前、第2章で記録が出どころを示し、第3章で全容が明かされる。
- **ジレンマ（「守る順番」）**：二千人の水を送るポンプか、温室の六人か。エンジュは合理的にポンプを優先し、三人は「一人でポンプを守り、二人で救助する」危険な分担を押し通す。この「順番」は第5章で三人が決め直し、最終章でエンジュ自身を「最後」にさせない形で回収する。
- **秘密（二面性）**：破片を拾った選択キャラは仲間に黙り、エンジュは口止めする。第2章でヒルギに「何かを隠してる顔」と見抜かれ、第3章で自分から打ち明ける。仲間は「知ってた」と受け止める。
- **第二の謎**：旧人類の姿をした者たちが「昔なにをしたのか」。第4章でケシが答える——水を奪い合い、森を焼き、足で追いかけた。だから祖先は根を張った（「動けなければ、奪いに行けない」）。第5章で、三人は水を「運ぶ」ために足を使い、その意味を反転させる。

### 真相と結末

- 白蓮保管庫は、根を張った人類が手放した肉体を眠らせる塔。番人は槐の市民エンジュで、二百年、保管庫の制御室に根を張っている。司令として声だけで登場していたのはそのため。
- 一年前、下層が浸水して眠る肉体が黒く崩れ、自己増殖する卵になった。天井が裂けて街へ降り、市民は異界から来たと思った。エンジュは訂正しなかった。卵は水路をさかのぼり、同じ物質でできた三人の後を追う（第2章の記録、ヒルギが「卵と同じ匂い」と叫んだ理由）。
- エンジュは崩れる前の三体を目覚めさせ、草木の名を付けた。三人の体は保管庫の核「白蓮」と繋がっており、卵を食べると傷が治るのは同じ物質だから。
- 一斉孵化の夜に白蓮が咲くと、卵は人の形で孵り、水を奪いに歩き出す（`invasive-source.png` の人型）。エンジュは三人を白蓮と心中させるつもりで作った（第5章で告白）。
- 第4章でリンドウが、三人の体は「水を飲み、食べ、眠った分だけ」自分の体に置き換わりつつある（生き残る確率は五分五分）と示す。白蓮は保管庫へ引かれた水で咲くため、市民は孵化の夜まで四つの区の水を止めると決める。動けない側にも払える代償として、ケシが「渇くことならできる」と言う。
- 第5章でその代償が来る。古株のニレが枯れかけ、三人は水路に繋がらない旧貯水池から、歩いて水を運ぶ。
- 最終章で白蓮を砕き、三人は鳥の形と卵による回復を失って生き残る。エンジュを土ごと移動槽で運び出し、ハスノ区の戸口の内側へ入る。

## 台本上の声

- ツキミ：問いを立てる人。状況を整理して作戦を出すが、「どうして」を口にして止まる癖がある。民間人には丁寧語。
- アカメ：まず自分が引き受けようとする。「触らないで」と言われれば本当に触らない頑固さ。感想を言わず、行動で気遣う。
- キイチゴ：軽口で痛みを逸らす。傷ついたことを冗談の形で一度だけ漏らす。卵の味の話を平気でする（後で意味が反転する）。
- エンジュ：数字と順番で話す。冷たいのではなく、守れる最大数を選び、自分はいつも最後に置く。保管庫の番人として真実を伏せていた。
- ミナリ：ハス型の住民代表。兵士の姿に怯えるが、「人が先」と自分で決め、怖さと感謝を分けて語る。
- リンドウ：殻のある観測係。命令の隙間で種の箱を持ち帰らせた側に「屁理屈」と返す。三人の体を測り、五分五分と告げる。
- ヒルギ：マングローブ型のシラユリ観測員。三人に「触らないで」と叫んだ本人。怖いと言いながら、記録を見るために運ばれることを選ぶ。隠しごとをしている人の顔が分かる。
- ケシ：旧人類の姿を嫌悪する。助けられたからこそ怖い。第4章で過去を語り、水を止める決断を最初に言う。第5章で「水の分の礼」とだけ言い、最後は「靴は脱いで」で迎え入れる。
- クヌギ：救助された若い市民。先入観より、運ばれたときの事実で兵士を見る。最初に三人の名前を呼ぶ。
- ニレ：避難所でいちばん古い株。台詞はない。水を止めた代償を、葉の色で見せる。

## 章構成と実装範囲

| 章 | 日 | 戦闘マップ（`src/campaign.js`） | 出撃前 | 戦闘後 |
| --- | --- | --- | --- | --- |
| 第1章「守る順番」 | 一斉孵化まで六日 | 草原・昼 | ポンプか六人か。一人でポンプを守る | 「白い破片」：殻に白蓮保管庫の名、エンジュの口止め |
| 第2章「シラユリの記録」 | 五日 | 草原・夕方 | 叫んだ観測員ヒルギを運び、観測所の入口を守る | 「同じ匂い」：卵は保管庫から来て三人を追う。記録の写しを託される |
| 第3章「水底に残るもの」 | 四日 | 水没・昼 | 保管庫の水没した下層へ | 「空の保管槽」：空の槽、名札、制御室のエンジュ、真相 |
| 第4章「根の誓い」 | 二日 | 草原・夜（暗い青の光） | 真実を告げて拒まれ、それでも避難所を守る | 「渇くことなら」：五分五分、水を止める決断 |
| 第5章「水を運ぶ足」 | 一日 | 水没・乾いた夕方 | ニレが枯れかけ、旧貯水池へ水を汲みに行く | 「奪わない足」：ニレの葉が開く。エンジュの告白 |
| 最終章「白蓮」 | 一斉孵化の夜 | 水没・赤い光、母卵は「白蓮の核」 | 市民に名前を呼ばれて出撃 | エンディング「根のない朝」 |

母卵の耐久は章ごとに1.0→1.1→1.2→1.3→1.45→1.6倍。キャラクターは第1章の前に一度だけ選び、最終章まで同じ兵士で進む（破片を持つ本人の視点で物語が続くため）。勝利すると帰還後の会話を再生し、進行を `localStorage` に保存して「次の章へ」を出す。ゲームは再読み込みで作り直す構造なので、次に始める章は `sessionStorage` で渡し、再読み込み後はタイトルを飛ばして出撃前会話から始める。最終章のクリアで保存を消す。敗北・時間切れでは帰還会話を再生せず「この章をやり直す」を出す。

救助・護衛・避難所の防衛・水運び・白蓮の破壊は台本で描き、戦闘は各章とも「卵を減らして母卵を壊す」共通ルール。護送AI、ポンプや避難所の耐久値、章固有の勝敗条件、新しい地域背景や戦闘中のNPCモデルは追加していない。章ごとの違いは地形・光・霧・母卵の耐久倍率だけ。
出撃前の制限時間の台詞は `Config.map.playSeconds` と `motherSpawnSeconds` に合わせ、全章についてテストで一致を確認する。日数のカウントダウンが逆戻りしないこともテストで確認する。

損失を語る部分は軽口を止める。市民の嫌悪を救助で解決させず、ケシは最後まで正面からの礼を言わない。物流の細部（流量・寸法・布の数）は、感情や選択を運ぶ物（肩当て、種の箱、白い破片、記録の殻、移動槽）に絞る。

## 検証

- `npm test`：全章・全キャラクターの台本、話者、表情、ページ長、伏線と回収の対応、章の進行保存。
- `npm run build`：本番ビルド。
- `npm run dev -- --port 5183` の起動後、Playwrightが利用できる環境で `node scripts/check-story.mjs`：実ブラウザで会話操作、全章の全ページのレスポンシブ表示、勝敗分岐、会話中の戦闘停止、再読、「次の章へ」「この章をやり直す」の表示を確認する。
- Playwrightが別の場所にある場合は `PLAYWRIGHT_MODULE` にそのモジュールのパスを指定。`STORY_TEST_URL`でテスト先URL、`STORY_TEST_BROWSER`でブラウザチャネルを指定可能（既定はmsedge）。
- ブラウザ検証では、テスト時のHTTP応答だけに状態参照を追加して母卵撃破・死亡・時間切れを発生させる。製品コードにはデバッグ用グローバルやクリア操作を追加しない。
